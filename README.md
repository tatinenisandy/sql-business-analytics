# SQL Business Analytics

A portfolio project demonstrating SQL-based business analytics, operational reporting and KPI measurement using synthetic data.

## Project Overview

This project explores how SQL can support business decision-making through structured data analysis.

## Files

- `01_setup.sql` — Database setup and sample data
- `02_kpis.sql` — Queries for business performance analysis

## Skills Demonstrated

- SQL querying
- Data aggregation
- Business KPI reporting
- Operational analytics
- Data-driven decision-making

## How to Use

1. Review `01_setup.sql` to understand the database structure.
2. Run the setup script in a compatible SQL environment.
3. Run `02_kpis.sql` to explore the KPI queries.

## Data

This project uses synthetic sample data for demonstration purposes. No confidential customer or employer data is included.
